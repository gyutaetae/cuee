# User Intervention

이 파일은 인간 개입이 필요한 운영/개발 절차를 기록한다.

## 접근성 설정
Android 정책상 큐는 접근성 권한을 자동으로 켤 수 없다. 사용자가 설정 화면에서 직접 `큐`를 켜야 한다.

## 앱 업데이트 대응
쿠팡, 카카오톡, 코레일톡 UI 업데이트로 노드 탐색이 깨질 수 있다. V1은 서버 사전 업데이트를 하지 않고, 직접 테스트 후 앱 업데이트로 대응한다.

## 민감 화면
결제, 송금, 주문 확정, 구매 확정, 인증번호, 비밀번호, 카드/계좌 화면에서는 큐가 안내를 중단한다. 사용자가 “입력칸 위치만 알려달라”고 명확히 요청한 경우 입력칸 위치 안내만 허용한다.

## 하네스 운영
이 프로젝트는 `gyutaetae/codex-harness`를 사용한다. 대화형 Codex 세션에서 `하네스 시작: <요구사항>`으로 문서 생성과 task/phase 생성을 진행하고, 생성된 task는 `python scripts/run_phases.py {id}-{name}`으로 실행한다. 실행 전 워킹트리가 깨끗해야 하며, 중요한 작업은 먼저 커밋한다.

## 실기기 검증
접근성 서비스와 오버레이는 실제 기기에서 반드시 검증한다. Android Studio/ADB 설치, USB 디버깅 활성화, 지원 앱 설치가 필요하다.
