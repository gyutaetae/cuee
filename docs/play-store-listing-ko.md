# Google Play 스토어 등록정보 초안

## 앱 이름

큐 - 코레일+ 쉬운 이용 안내

## 간단한 설명

코레일+에서 다음에 직접 누를 곳을 한 단계씩 알려 주는 접근성 도구

## 자세한 설명

큐는 인지적 어려움이나 디지털 사용의 어려움이 있는 사용자가 코레일+ 화면을 더 쉽게 이해하도록 돕습니다.

- 한 번에 다음 행동 한 곳만 크게 강조합니다.
- 쉬운 한국어 음성으로 다음 단계를 설명합니다.
- 출발역과 도착역 검색을 도와줍니다.
- 로그인, 개인정보, 열차 선택, 예매와 결제는 사용자가 직접 확인합니다.
- 언제든 안내를 종료하고 접근성 기능 동의를 철회할 수 있습니다.

큐는 화면 원문과 음성 원문을 개발자 서버에 저장하지 않습니다. 음성 인식은 Android 기기에 설정된 음성 서비스가 처리할 수 있습니다.

큐는 한국철도공사 또는 코레일+의 공식 앱이 아니며, 해당 기관과 제휴하거나 보증받지 않았습니다. 코레일+ 화면 변경에 따라 일부 안내가 일시적으로 동작하지 않을 수 있습니다.

## 그래픽 준비 목록

- 앱 아이콘: 512×512 PNG
- 기능 그래픽: 1024×500 PNG/JPG
- 휴대전화 스크린샷: 실제 앱 고지, 한 단계 강조, 안전 중지 화면 4~8장
- 심사용 영상: 접근성 고지부터 안전 중지까지 실제 동작

스크린샷과 영상에는 계정, 이름, 전화번호, 승차권과 결제정보가 노출되지 않아야 합니다.
