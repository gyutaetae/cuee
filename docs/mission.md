# Mission

## 제품
큐(cuee)는 고령 사용자가 Android 앱을 쓰다가 막혔을 때 화면 위 동그라미를 누르고 말하면, 다음에 눌러야 할 곳만 남기고 나머지를 하얗게 가려주는 접근성 길잡이다.

## 핵심 가치
- 사용자가 직접 누른다. 큐는 자동 클릭하지 않는다.
- 못 찾으면 솔직히 말한다. 신뢰가 기능보다 중요하다.
- 좁은 범위에서 진짜 잘 된다. MVP 목표는 지원 명령 30회 중 27회 이상 성공이다.
- 개인정보는 기기 밖으로 보내지 않는다. 서버, 로그인, AI API 없이 시작한다.
- 결제, 송금, 주문 확정, 구매 확정, 보내기 버튼은 안내하지 않는다.

## 초기 고객
스마트폰 앱에서 버튼 위치, 입력칸, 다음 행동을 찾기 어려운 한국 고령 사용자. 보호자가 대신 조작하는 제품이 아니라, 고령 사용자가 직접 쓸 수 있는 길잡이를 지향한다.

## MVP 범위
지원 앱은 쿠팡, 카카오톡, 코레일톡 3개로 제한한다.

지원 명령:
- 쿠팡 상품 찾기
- 쿠팡 장바구니 보기
- 카카오톡 메시지 입력
- 카카오톡 사진/앨범 버튼 찾기
- 코레일톡 예매한 표 보기
- 코레일톡 승차권 예매 찾기

## 비즈니스 가설
고령 사용자와 가족은 “모든 것을 대신하는 AI”보다 “사고 치지 않고 옆에서 알려주는 도구”를 더 신뢰한다. 초기 유료화는 보호자/가족 대상 월 구독 또는 고령자 디지털 케어 번들로 검증한다.
