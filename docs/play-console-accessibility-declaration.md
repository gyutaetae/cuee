# Play Console 접근성 서비스 신고 초안

## `isAccessibilityTool`

- 설정값: `true`
- 근거: 앱의 주목적은 인지적 어려움이나 디지털 사용의 어려움이 있는 사용자가 코레일+ 화면을 이해하고 직접 조작하도록 단계별 시각·음성 안내를 제공하는 것입니다.

## 핵심 기능 설명

큐는 사용자가 음성으로 도움을 요청한 뒤 현재 코레일+ 화면의 접근성 노드를 읽습니다. 다음에 직접 눌러야 할 한 영역만 강조하고 쉬운 한국어 음성으로 설명합니다. 사용자가 안내를 취소하거나 동의를 철회할 수 있으며 로그인, 개인정보, 열차 선택, 예매와 결제는 자동으로 수행하지 않습니다.

## AccessibilityService가 필요한 이유

- 다른 앱인 코레일+ 화면의 현재 글자, 역할과 위치를 읽어야 합니다.
- 선택 대상 위에 접근성 오버레이를 표시해야 합니다.
- 역 검색어 입력과 시간 목록 스크롤을 제한적으로 보조합니다.
- 일반 권한이나 더 좁은 Android API만으로는 다른 앱 화면의 현재 상태와 대상 위치를 파악할 수 없습니다.

## 접근·수집·공유 설명

- 일시 접근: 코레일+ 화면의 글자, 버튼 이름, 위치 및 화면 상태
- 기기 내 저장: 동의 시각, 설정, 작업 종류·시간·결과·중단 사유·단계 수
- 저장하지 않음: 화면 원문, 음성 원문, 로그인 정보, 결제 정보
- 개발자 서버 공유: 없음
- 외부 처리 가능성: Android 음성 인식 제공자가 기기 설정에 따라 음성을 처리할 수 있음

## 심사용 영상 구성

1. 앱 첫 실행의 접근성 기능 고지 전체를 천천히 보여 줍니다.
2. `동의하고 계속`을 누른 뒤 Android 접근성 설정에서 큐를 켭니다.
3. 코레일+ 홈에서 큐 버튼을 누르고 음성 명령을 말합니다.
4. 출발역 등 다음 행동 한 곳만 강조되고 사용자가 직접 누르는 모습을 보여 줍니다.
5. 로그인 또는 결제 전 화면에서 큐가 중지되는 모습을 보여 줍니다.
6. 앱 홈에서 동의 철회가 가능한 것을 보여 줍니다.

영상은 실제 코레일+에서 촬영하되 로그인 정보, 이름, 전화번호, 승차권 및 결제정보를 가리고 실제 구매는 완료하지 않습니다.
