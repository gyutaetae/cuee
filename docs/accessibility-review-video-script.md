# CUEE 접근성 Permission Declaration 소명 영상 촬영 대본

Play Console의 AccessibilityService Permission Declaration Form에 첨부할 소명 영상 대본이다.
이 영상 없이는 폼을 제출할 수 없고, 폼 승인 없이는 배포가 불가능하다(targetSdk 36 + AccessibilityService).

## 정책이 반드시 담으라고 요구하는 장면 (누락 시 반려)

Google 정책 원문 기준 필수 항목:
1. 기기에서 앱을 여는 장면
2. 접근성 사용 고지(prominent disclosure)와 동의 화면까지 가는 사용자 흐름 — 스크롤이 필요하면 천천히 스크롤해 전문이 보이게
3. 사용자가 **동의**하고 접근성 권한을 켜는 흐름
4. 사용자가 **동의하지 않는** 흐름(고지를 다시 띄우는 과정 포함)
5. 접근성 기능을 실제로 쓰는 핵심 기능. UI만으로 사용 방식이 자명하지 않으면 음성 해설 또는 자막을 넣을 것

주의: 인앱 고지는 `AccessibilityService_description`/`htmlDescription`으로 대체할 수 없다. 반드시 앱 내부의 별도 고지 화면을 보여줘야 한다.

## 촬영 조건

- 실제 기기(삼성 등)에서 실제 코레일+ 설치·로그인 상태로 촬영. mock-korail이 아님.
- 화면 녹화 + 음성 해설(또는 자막) 권장. 한국어 나레이션 가능.
- 로그인 정보, 이름, 전화번호, 승차권·결제 정보는 가리거나 모자이크. 실제 결제는 완료하지 않는다.
- 길이 2~4분 권장. 유튜브 '미등록(unlisted)'로 올리고 링크를 폼에 붙인다.
- 세로 화면, 큰 글꼴 설정을 켜두면 접근성 도구라는 점이 더 잘 드러난다.

## 장면별 대본 (촬영 순서 그대로)

### 장면 1 — 앱 열기와 정체성 (0:00~0:20)
- 홈 화면에서 '큐' 아이콘을 눌러 앱을 연다.
- 나레이션: "큐는 인지적 어려움이나 디지털 사용이 어려운 분, 복잡한 예매 화면이 막막한 고령 사용자가 코레일+를 스스로 이용하도록 돕는 접근성 도구입니다."

### 장면 2 — 인앱 고지 전문 (0:20~0:55) [정책 필수 2]
- 첫 실행 시 뜨는 접근성 사용 고지 화면을 보여준다.
- 텍스트가 길면 **천천히 스크롤**해 처음부터 끝까지 전부 화면에 나오게 한다.
- 나레이션: "큐가 어떤 화면 정보와 음성을 처리하는지, 그리고 무엇을 저장하지 않는지 사용자에게 먼저 안내합니다. 화면 원문과 음성 원문은 저장하지 않습니다."

### 장면 3 — 거부 흐름 (0:55~1:20) [정책 필수 4, 먼저 촬영]
- 고지 화면에서 **동의하지 않음/닫기**를 선택하는 모습을 보여준다.
- 앱이 접근성을 켜지 않고 멈추는 것을 보여준다.
- 다시 고지 화면을 띄우는 경로(앱 재실행 또는 홈의 안내 버튼)를 보여준다.
- 나레이션: "동의하지 않으면 큐는 접근성 기능을 켜지 않고, 언제든 다시 고지를 확인할 수 있습니다."

### 장면 4 — 동의와 권한 켜기 (1:20~1:50) [정책 필수 3]
- 이번엔 '동의하고 계속'을 누른다.
- '접근성 설정 열기' → Android 설정에서 '큐' 접근성 서비스를 **켜는 전 과정**을 보여준다.
- (음성 명령 쓸 때만) 마이크 권한 허용을 사용자 행동으로 누르는 모습.
- 나레이션: "동의하면 접근성 설정으로 이동해 사용자가 직접 큐를 켭니다."

### 장면 5 — 핵심 기능 실제 사용 (1:50~3:00) [정책 필수 5]
- 코레일+ 승차권 예매 홈에서 큐 버튼을 누른다.
- "진주에서 서울 가는 표 예매해줘"라고 말한다.
- 큐가 다음 누를 곳(출발역)만 초록색으로 강조하고, 사용자가 **직접** 누르는 모습.
- 역 검색 입력 보조 → 날짜/시간/인원 안내 → 열차 조회를 사용자가 직접 누르는 흐름.
- 강조된 열차 후보 중 사용자가 직접 선택하는 모습.
- 나레이션(핵심): "큐는 대신 예매하지 않습니다. 다음에 직접 누를 한 곳만 강조하고, 모든 선택과 탭은 사용자가 합니다."

### 장면 6 — 결제 전 안전 종료 (3:00~3:30) [자동화 아님을 증명하는 결정적 장면]
- 예매/결제 진입 화면에서 큐가 **안전 안내 후 멈추는** 모습을 보여준다.
- 나레이션: "로그인, 개인정보, 결제 화면에서 큐는 안내를 멈춥니다. 결제는 사용자가 직접 확인합니다."
- 이 장면이 "자율적으로 계획·실행하지 않는다"는 정책 요건을 시각적으로 증명한다.

## 폼 텍스트 답변 (영상과 함께 제출)

`docs/play-console-accessibility-declaration.md`의 내용을 폼 항목에 매핑:
- 핵심 기능 1개: 현재 코레일+ 화면의 접근성 노드를 읽어 다음에 직접 누를 한 곳을 강조·음성 안내
- 대상 장애 유형: 인지 또는 학습(Cognitive or learning), 기타(고령·디지털 취약)
- 대상 사용자: 복잡한 예매 화면을 어려워하는 인지적 어려움 사용자 및 고령 사용자
- 영상 링크: (위에서 올린 unlisted 링크)

## 촬영 전 최종 체크

- [ ] 실제 코레일+ 로그인 상태, 큐 설치 상태
- [ ] 개인정보/결제정보 가림 처리 계획 확인
- [ ] 6개 장면 순서대로, 필수 5항목(열기·고지 전문·거부·동의/켜기·핵심기능) 모두 포함
- [ ] 결제 전 안전 종료 장면 포함
- [ ] 음성 해설 또는 자막
- [ ] unlisted 업로드 후 링크가 열리는지 확인
