큐(CUEE) 개인정보 처리방침

시행일: 2026년 8월 29일

1. 목적과 적용 범위

큐는 인지적 어려움이나 디지털 사용의 어려움이 있는 사용자가 코레일+에서 다음 행동을 찾도록 돕는 Android 접근성 도구입니다. 큐는 한국철도공사 또는 코레일+의 공식 앱이 아니며, 해당 기관과 제휴하거나 보증받지 않았습니다.

2. 처리하는 정보

  • 접근성 정보: 안내 중인 코레일+ 화면의 글자, 버튼 이름, 화면 위치와 화면 전환 상태
  • 음성 정보: 사용자가 큐 버튼을 누른 뒤 말한 음성과 Android 음성 인식 결과
  • 기기 내 설정: 접근성 기능 동의 시각, 말풍선 위치와 사용 여부, 음성 사용 여부
  • 기기 내 사용 결과: 작업 종류, 시작·종료 시각, 소요 시간, 성공 여부, 중단 사유와 단계 수

3. 이용 목적

  • 다음에 사용자가 직접 누를 안전한 영역을 찾고 강조
  • 안내 문구를 음성으로 출력
  • 역 검색어 입력과 시간 목록 이동 보조
  • 로그인, 개인정보, 열차 선택, 예매 및 결제 화면에서 자동 안내 중지
  • 기기 내에서 최근 사용 결과를 보존해 기능의 안정성을 확인

4. 저장, 전송과 보유기간

큐는 화면 원문과 음성 원문을 저장하거나 개발자 서버로 전송하지 않습니다. 설정과 사용 결과는 사용자의 기기에만 저장되며 사용 결과는 최근 200건으로 제한됩니다. 앱의 저장공간을 삭제하거나 앱을 제거하면 이 정보가 삭제됩니다.

5. 제3자 처리

음성 인식과 음성 출력은 사용자의 Android 기기에 설정된 서비스가 처리할 수 있습니다. 네트워크 전송 여부와 보유 방식은 해당 음성 서비스 제공자와 사용자의 기기 설정에 따라 달라질 수 있습니다. 큐 개발자는 해당 서비스가 처리하는 음성 원문을 수신하거나 저장하지 않습니다.

6. 이용자의 선택과 철회

이용자는 마이크 권한을 허용하지 않고도 접근성 설정 화면을 확인할 수 있습니다. 앱 홈의 접근성 기능 동의 철회를 누르거나 Android 접근성 설정에서 큐를 끌 수 있습니다. 기기 설정에서 마이크 권한도 언제든 철회할 수 있습니다.

7. 아동과 법정대리인

큐는 아동을 별도 대상으로 설계하지 않았습니다. 도움이 필요한 사용자가 법정대리인 또는 보호자와 함께 사용하는 경우에도 최종 예매와 결제 선택은 사용자 또는 보호자가 직접 확인해야 합니다.
