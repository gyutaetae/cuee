# 본문

## 표를 구하지 못하는 이유가 좌석이 없어서가 아니라면?

교통·금융·쇼핑 등 일상 서비스가 모바일 앱 중심으로 빠르게 전환되고 있습니다. 하지만 복잡한 메뉴와 작은 버튼, 익숙하지 않은 결제 과정은 시니어에게 새로운 장벽이 됩니다.

스마트폰을 가지고 있어도 다음에 무엇을 눌러야 하는지 찾지 못하면 예매는 중단됩니다. 자녀에게 전화를 걸거나 현장 창구로 이동해야 하고, 기업은 이미 유입된 고객을 거래 직전에 놓치게 됩니다.

CUEE는 이 문제를 교육이 아닌 **실시간 수행 보조**로 해결합니다.

> 사용법을 외우게 하지 않고, 필요한 순간에 다음 행동만 보여줍니다.

### 슬라이드 1 — CUEE

CUEE는 디지털 취약계층이 복잡한 앱을 스스로 사용할 수 있도록 돕는 모바일 화면 길잡이입니다.

### 슬라이드 2 — 문제 정의

교통 서비스가 비대면 중심으로 전환되면서 앱 사용에 익숙하지 않은 시니어는 이동권과 소비권에서 소외되고 있습니다.

### 슬라이드 3 — 문제와 시장 기회

시니어의 스마트폰 접근 수준은 높지만 실제 활용 역량에는 여전히 큰 격차가 있습니다. CUEE는 이 간극을 기업의 접근성 개선과 신규 고객 전환 기회로 바라봅니다.

### 슬라이드 4 — 기존 해결 방식의 한계

가족의 대리 예매와 반복 교육은 지속 가능한 해결책이 아닙니다. 사용자가 혼자 남은 실제 상황에서도 바로 작동하는 보조 수단이 필요합니다.

### 슬라이드 5 — 경쟁 대안과 차별성

기존 서비스가 사용법을 가르친다면 CUEE는 사용 순간에 개입합니다. 별도의 강사나 오프라인 창구 없이 화면 위에서 즉시 다음 행동을 안내할 수 있어 확장성이 높습니다.

## CUEE는 어떻게 작동하나요?

사용자가 원하는 목적을 말하면 CUEE는 현재 앱 화면의 구조를 분석합니다. 이후 눌러야 할 버튼을 제외한 나머지 영역을 마스킹하고, 사용자가 다음 행동을 직접 선택하도록 돕습니다.

1. 사용자가 음성으로 목적을 말합니다.
2. CUEE가 현재 화면 구조와 버튼 후보를 분석합니다.
3. 다음에 눌러야 할 영역만 강조합니다.
4. 사용자가 직접 확인하고 버튼을 누릅니다.
5. 화면이 바뀌면 다음 행동을 이어서 안내합니다.

CUEE는 사용자를 대신해 예약하거나 결제하지 않습니다. 로그인·약관·개인정보·예약 확정·결제처럼 중요한 판단이 필요한 순간에는 자동 행동을 제한하고 사용자가 직접 결정하도록 합니다.

### 슬라이드 6 — 솔루션 기능 원리

현재 MVP는 Android Accessibility Service와 화면 구조 분석, 오버레이 마스킹을 이용해 실제 코레일톡 화면 위에서 동작합니다.

### 슬라이드 7 — 솔루션 흐름

한 번의 요청 이후 화면 변화를 계속 분석해 경로 설정, 날짜와 인원 선택, 열차 후보 확인, 결제 진입 전 단계까지 다음 행동을 안내합니다.

## 현재 어디까지 구현했나요?

현재 CUEE는 실제 Android 코레일톡에서 `진주→서울` 예매 시나리오를 안내하는 MVP를 구현했습니다.

- 실제 코레일톡 화면 구조 분석
- 출발지와 도착지 설정 안내
- 날짜·시간·인원 선택 안내
- 매진·예약대기·외부 링크를 제외한 열차 후보 분석
- 결제 진입 전 안전 정지
- 실제 기기 기반 테스트와 동작 영상 확보

아직 모든 앱과 자유로운 명령을 지원하는 단계는 아닙니다. 하나의 시나리오를 안정적으로 완성한 뒤 시니어 사용성 테스트를 통해 무보조 이용 대비 예매 시간을 50% 단축할 수 있는지 검증할 계획입니다.

Porcupine 호출어 감지, STT·SLM 기반 자유 명령 분석과 여러 앱을 지원하는 범용 화면 안내는 이후 확장 단계에서 적용합니다.

## 기업에는 어떤 가치가 있나요?

CUEE의 주 고객은 교통·모빌리티·이커머스 플랫폼 기업입니다.

기업은 이미 앱에 들어온 시니어 고객이 복잡한 화면 때문에 거래를 중단하는 문제를 겪습니다. CUEE는 고객이 스스로 다음 단계로 이동하도록 도와 접근성을 높이고, 중도 이탈을 실제 거래 전환으로 연결합니다.

초기 비즈니스 모델은 **성과 기반 CPS 제휴**입니다. 기업의 초기 도입 부담을 낮추고, CUEE의 안내를 통해 거래가 성사됐을 때 성과를 공유하는 구조입니다. 구체적인 수수료율과 시장 규모는 사용자 검증과 플랫폼 협의를 통해 고도화할 초기 가설입니다.

### 슬라이드 8 — B2B 비즈니스 모델

CUEE는 사용자에게 디지털 장벽 없는 경험을 제공하고, 플랫폼에는 신규 고객 확보와 구매 전환율 개선 가능성을 제공합니다.

### 슬라이드 9 — 시장 규모

교통 예매를 첫 시장으로 삼아 실버테크와 디지털 접근성 시장으로 확장합니다. 현재 수치는 사업 가능성을 검토하기 위한 초기 추정치이며, 실증 결과와 제휴 논의를 통해 구체화할 예정입니다.

## 왜 코레일톡부터 시작하나요?

교통 예매는 시니어의 이동권과 바로 연결되고, 실패했을 때 가족의 대리 예매·콜센터·현장 창구로 비용이 전가되는 영역입니다.

CUEE는 문제의 강도가 높은 코레일톡 예매에서 기술과 사용자 가치를 먼저 검증합니다. 이후 버스와 다른 모빌리티 플랫폼, 금융·쇼핑·공공 서비스로 적용 범위를 넓혀갈 계획입니다.

### 슬라이드 10 — 확장 전략

초기에는 교통 플랫폼과 B2B 제휴를 추진하고, 지자체·복지기관·공공기관 실증을 거쳐 금융·쇼핑·공공 서비스로 확장합니다.

### 슬라이드 11 — 로드맵

현재 MVP 고도화와 시니어 사용성 테스트를 우선 진행합니다. 검증 결과를 바탕으로 앱 안정화와 플랫폼 제휴 가능성을 확인합니다.

### 슬라이드 12 — 비전

CUEE의 목표는 디지털 사용법을 잘 아는 사람만 누릴 수 있는 편리함을 모두에게 확장하는 것입니다. 누구나 스스로 이동하고 소비할 수 있는 디지털 접근성 환경을 만들겠습니다.

## 실행할 수 있는 팀

CUEE는 개발·기획·디자인·비즈니스 역량을 갖춘 경상국립대학교 학생 창업팀입니다.

- **김규태｜대표·기술 총괄**  
  Android MVP 개발과 시스템 아키텍처 설계를 담당합니다.

- **김주원｜UI/UX·마케팅**  
  시니어 관점의 사용자 경험과 서비스 커뮤니케이션을 설계합니다.

- **박나현｜UI/UX·BX 디자인**  
  직관적인 화면 경험과 CUEE 브랜드 디자인을 담당합니다.

- **박준영｜시장 분석·BM 전략**  
  시장 데이터 분석과 B2B 사업모델 고도화를 담당합니다.

- **손홍모｜서비스 기획·개발 QA**  
  스타트업 개발 QA 인턴 경험을 바탕으로 서비스 기획과 제품 검증을 담당합니다.

### 슬라이드 13 — 팀 역할과 역량

우리는 아이디어를 발표하는 데서 멈추지 않고 실제 코레일톡에서 동작하는 MVP를 구현했습니다. 개발·디자인·시장 검증을 한 팀 안에서 빠르게 반복하며 실현 가능성을 증명해 나가겠습니다.

## 게시 전 사실 확인 메모

- 인터뷰와 사용성 테스트는 아직 실시하지 않았으며 목표 수치를 성과처럼 표현하지 않는다.
- 현재 구현은 실제 Android 코레일톡의 `진주→서울` 고정 시나리오다.
- Porcupine·SLM·다중 앱 지원은 향후 확장 계획이다.
- 복지관 자문 및 테스트베드 연계는 확정 성과가 아닌 추진 계획이다.
- CPS 10%와 시장 규모는 검증 전 초기 가설이다.
- 유튜브 링크는 업로드 후 교체한다.
