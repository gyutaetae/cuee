# cuee

코레일톡에서 예매나 표 확인에 실패하는 사용자가 **다음에 눌러야 할 곳만 보고 직접 누를 수 있게 하는 Android 접근성 오버레이**입니다.

cuee는 사용자를 대신해 예매해주는 앱이 아닙니다. 복잡한 화면에서 지금 눌러야 할 영역만 남겨, 사용자가 스스로 거래를 이어가게 돕습니다.

## 문제

코레일톡 같은 필수 앱에서 사용자가 실패하는 이유는 기능이 없어서가 아니라, 복잡한 화면에서 **다음 행동을 찾지 못하기 때문**입니다.

실패는 단순 불편으로 끝나지 않습니다.

- 기차 시간에 맞춰야 하는 상황에서 예매를 끝내지 못함
- 예매한 표를 찾지 못해 역이나 개찰구 앞에서 당황함
- 가족이나 지인에게 반복적으로 도움을 요청함
- 원격 조작을 부탁하면서 개인정보와 결제 화면 노출을 감수함
- 결국 창구, 고객센터, 현장 직원에게 부담이 이동함

이 문제는 고령자에게 가장 자주 보이지만, 본질은 나이가 아닙니다. 코레일톡 사용 경험이 낮은 사람, 인지 부담이 큰 사람, 방한 외국인도 같은 지점에서 멈춥니다.

cuee의 타깃은 **모바일 거래 실패율이 높은 사용자**입니다.

## 해결

사용자는 코레일톡에서 cuee 버튼을 누르고 말합니다.

- "승차권 예매 찾기"
- "예매한 표 보여줘"

cuee는 현재 화면을 분석한 뒤, 눌러야 할 영역만 남기고 나머지를 가립니다. 사용자는 남은 영역을 직접 누릅니다.

핵심 경험은 단순합니다.

1. 사용자는 화면 전체를 이해하지 않아도 됩니다.
2. cuee는 선택지를 줄여줍니다.
3. 사용자는 직접 판단하고 직접 누릅니다.

중요한 점은 cuee가 사용자의 행동을 빼앗지 않는다는 것입니다. 대신 누르지 않기 때문에 사용자는 자신이 무엇을 눌렀는지 알 수 있고, 결제·로그인·인증·개인정보·예매 확정 같은 민감한 순간에는 안내를 멈출 수 있습니다.

우리가 줄이려는 것은 앱 사용 시간이 아니라 **실패해서 멈추는 시간**입니다.

## 고객

초기 구매자는 보호자입니다. 직접 사용자는 부모님이나 코레일톡 사용에 어려움을 겪는 사람입니다.

보호자가 돈을 낼 이유는 명확합니다.

- 부모님의 반복적인 도움 전화가 줄어듦
- 원격 조작보다 안전함
- 디지털 교육보다 즉각적임
- 실제로 자주 발생하는 예매/표 확인 실패를 해결함

사용자 입장에서도 이점이 있습니다.

- 가족에게 매번 물어보지 않아도 됨
- 화면을 배우지 않아도 당장 필요한 행동을 할 수 있음
- 누군가에게 휴대폰 화면을 넘기지 않아도 됨
- 스스로 해냈다는 경험을 얻음

장기적으로는 코레일 같은 기업에 제공할 수 있습니다. 기업 입장에서는 사용자가 앱에서 거래를 끝내지 못할 때 발생하는 이탈, 고객센터 문의, 현장 창구 부담을 줄일 수 있습니다.

따라서 cuee의 사업 흐름은 두 단계입니다.

1. 보호자 B2C로 절박한 문제와 지불 의사를 검증합니다.
2. 코레일 같은 기업 대상 B2B 접근성 솔루션으로 확장합니다.

## 검증 목표

아이디어톤 MVP의 검증 목표는 기능 수가 아니라 완료율 개선입니다.

UT에서 확인할 지표:

- 코레일톡 예매/표 확인 완료시간 50% 감소
- 도움 요청 횟수 70% 감소
- 실패율 30%p 감소

우선 검증할 과제:

- 코레일톡에서 승차권 예매 시작하기
- 코레일톡에서 예매한 표 찾기

검증 대상:

- 코레일톡 사용 경험이 낮은 사용자
- 부모님의 코레일톡 사용을 도와본 보호자
- 모바일 예매 과정에서 자주 멈추는 고령 사용자
- 한국어 안내를 이해할 수 있는 외국인 시나리오 사용자

성공 기준은 사용자가 cuee를 한 번 보고 "다음에도 이 상황이면 다시 쓰겠다"고 느끼는 것입니다. 이 제품은 매일 오래 쓰는 앱이 아니라, 실패하면 손실이 큰 순간에 다시 켜지는 도구여야 합니다.
