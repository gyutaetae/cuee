# 큐(cuee) - 고령자를 위한 스마트폰 사용 길잡이

## 한 줄 소개

> 어디를 눌러야 할지 모르는 순간, 다음에 눌러야 할 곳만 보여주는 고령자용 스마트폰 길잡이

큐(cuee)는 고령 사용자가 쇼핑, 메신저, 교통 예매 앱을 이용하다가 막혔을 때 화면을 단순하게 만들어 다음 행동을 스스로 할 수 있도록 돕는 서비스입니다.

핵심은 "대신 해주는 서비스"가 아니라 "혼자 할 수 있게 도와주는 서비스"입니다. 사용자의 자율성과 안전을 지키면서 디지털 생활의 진입 장벽을 낮추는 것이 큐의 방향입니다.

## 문제

고령층은 스마트폰을 보유하고 있어도 실제 앱 사용 과정에서 자주 막힙니다. 버튼이 많고, 화면 구성이 자주 바뀌며, 다음에 무엇을 눌러야 하는지 알기 어렵기 때문입니다.

특히 쿠팡 같은 쇼핑 앱, 카카오톡 같은 메신저, 코레일톡 같은 교통 예매 앱은 일상생활에 꼭 필요하지만 고령 사용자에게는 난도가 높은 서비스입니다. 사용자가 막힐 때마다 가족에게 물어보거나 원격으로 조작을 부탁해야 하는 상황이 반복됩니다.

이 문제는 단순한 불편을 넘어섭니다.

- 고령 사용자의 디지털 자립성이 낮아집니다.
- 가족과 보호자의 반복적인 도움 부담이 커집니다.
- 결제, 송금, 개인정보 화면에서는 불안과 보안 위험이 생깁니다.
- 디지털 서비스가 확산될수록 소외 격차가 더 커집니다.

## 해결

큐는 사용자가 "물티슈 찾아줘", "예매한 표 보여줘", "사진 보내는 곳 알려줘"처럼 말하면 현재 화면에서 다음에 눌러야 할 부분만 남기고 나머지를 가려줍니다.

사용자는 복잡한 화면 전체를 이해할 필요 없이 눈에 보이는 영역을 직접 누르면 됩니다. 큐는 사용자의 행동을 빼앗지 않고, 사용자가 스스로 성공할 수 있도록 선택지를 줄여줍니다.

또한 결제, 송금, 주문 확정, 개인정보 입력처럼 위험하거나 민감한 행동은 안내하지 않습니다. 큐는 편리함보다 신뢰를 우선하는 서비스입니다.

## 차별성

| 구분 | 기존 방식 | 큐(cuee) |
|---|---|---|
| 가족에게 물어보기 | 매번 도움을 요청해야 함 | 사용자가 혼자 해결 가능 |
| 원격 조작 앱 | 타인이 대신 조작함 | 사용자가 직접 판단하고 누름 |
| 음성비서 | 앱 안의 구체적 버튼 안내가 약함 | 현재 화면에서 다음 영역을 직접 보여줌 |
| 일반 접근성 기능 | 기능이 많고 학습이 필요함 | 지금 필요한 행동만 단순하게 안내 |

큐의 차별점은 기술 자체보다 사용 방식에 있습니다. 고령 사용자가 앱 전체를 배우도록 요구하지 않고, 막힌 순간에 필요한 한 걸음만 안내합니다.

## 시장성

고령층의 스마트폰 사용은 이미 생활 필수가 되었습니다. 쇼핑, 메신저, 기차 예매, 병원 예약, 배달, 금융, 공공서비스까지 대부분의 생활 서비스가 모바일 중심으로 이동하고 있습니다.

하지만 실제 사용 능력은 보급률만큼 따라오지 못하고 있습니다. 이 간극은 큐가 해결하려는 명확한 시장 기회입니다.

### 초기 고객

- 스마트폰 사용에 어려움을 느끼는 고령 사용자
- 부모님의 스마트폰 사용을 반복적으로 도와야 하는 보호자 가족
- 디지털 교육을 운영하는 지자체와 복지기관
- 고령 고객 접근성을 강화하려는 플랫폼 기업

### 확장 가능한 시장

- 시니어 디지털 케어
- 통신사 부가서비스
- 지자체 디지털 포용 사업
- 커머스/교통/금융 앱의 접근성 개선 솔루션
- 보호자 대상 구독형 케어 서비스

## 성장가능성

큐는 특정 앱 몇 개를 돕는 도구에서 출발하지만, 장기적으로는 고령층의 모바일 생활 전반을 돕는 안내 플랫폼으로 성장할 수 있습니다.

1. 생활 필수 앱 확장
   쇼핑, 메신저, 교통에서 병원 예약, 배달, 공공서비스, 금융 앱으로 넓힐 수 있습니다.

2. 보호자 연결 모델
   보호자가 직접 대신 조작하는 방식이 아니라, 사용자가 어디서 막히는지와 어떤 도움이 필요한지만 확인하는 방향으로 확장할 수 있습니다.

3. 기관 제휴
   지자체, 복지관, 통신사, 시니어 교육기관과 결합하면 단순 앱을 넘어 디지털 포용 서비스로 자리 잡을 수 있습니다.

4. B2B 접근성 솔루션
   고령 고객이 많은 기업 앱에 큐의 안내 방식을 적용해 고객 이탈과 상담 부담을 줄일 수 있습니다.

## 와우포인트

큐의 가장 강한 포인트는 화면을 "설명"하는 것이 아니라 화면을 "쉬워 보이게 만든다"는 점입니다.

고령 사용자는 기능이 없어서 못 쓰는 것이 아니라, 너무 많은 버튼과 정보 속에서 다음 행동을 찾지 못해 멈춥니다. 큐는 그 순간 화면을 단순하게 바꿔 사용자가 직접 성공하는 경험을 만듭니다.

또 하나의 중요한 와우포인트는 안전한 포기입니다. 큐는 모든 것을 해내겠다고 말하지 않습니다. 결제, 송금, 개인정보처럼 위험한 순간에는 멈춥니다. 아이디어톤 관점에서 이 절제는 오히려 서비스 신뢰도를 높이는 강점입니다.

## 심사위원 관점 피드백

### 잘한 점

1. 문제 정의가 선명합니다.
   "고령층 디지털 소외"라는 넓은 문제를 "앱 화면에서 다음에 누를 곳을 모르는 순간"으로 좁힌 점이 좋습니다. 해결해야 할 장면이 구체적이기 때문에 서비스도 이해하기 쉽습니다.

2. 사용자의 존엄성을 지키는 방향입니다.
   누군가 대신 조작해주는 것이 아니라 사용자가 직접 할 수 있게 돕는다는 점이 좋습니다. 고령자를 수동적인 보호 대상으로만 보지 않는 접근입니다.

3. 초기 시장 진입이 현실적입니다.
   쿠팡, 카카오톡, 코레일톡처럼 사용 빈도가 높고 필요성이 큰 앱을 먼저 잡은 점이 설득력 있습니다. 문제 상황을 시연하기도 좋고, 사용자 반응을 검증하기도 좋습니다.

4. 신뢰 설계가 사업적으로 중요합니다.
   결제와 송금 같은 위험 행동을 일부러 제외한 점은 좋은 판단입니다. 고령자 대상 서비스에서는 기능 수보다 신뢰가 더 중요합니다.

5. 보호자 니즈까지 함께 건드립니다.
   사용자는 혼자 할 수 있어 좋고, 보호자는 반복적인 도움 부담이 줄어듭니다. 구매 의사결정자가 보호자일 수 있다는 점에서 사업화 가능성이 있습니다.

### 부족한 점

1. 사용자 검증 근거가 더 필요합니다.
   아이디어는 좋지만, 실제 고령 사용자가 얼마나 빨리 이해하는지, 도움 요청이 얼마나 줄어드는지에 대한 데이터가 아직 부족합니다.

2. 첫 유료 고객이 더 명확해야 합니다.
   고령 사용자 본인, 보호자 가족, 지자체, 통신사, 플랫폼 기업 중 어디를 먼저 공략할지 우선순위가 필요합니다.

3. 서비스가 커질수록 운영 전략이 중요합니다.
   지원 앱이 늘어나면 화면 변화와 고객 문의에 대응해야 합니다. 단순 기능 확장이 아니라 지속 운영 가능한 모델을 고민해야 합니다.

4. 경쟁 대안 대비 메시지가 더 날카로워야 합니다.
   음성비서, 원격지원, 디지털 교육과 비교했을 때 큐가 왜 더 빠르고 안전한 해결책인지 한 문장으로 더 강하게 정리할 필요가 있습니다.

5. 수익 모델 검증이 필요합니다.
   보호자 구독, 기관 납품, 기업 제휴 중 어떤 모델이 가장 현실적인지 작은 실험으로 확인해야 합니다.

## 더 성장시키면 좋은 점

- 고령 사용자 5~10명 대상 사용성 테스트를 진행해 성공률, 완료 시간, 도움 요청 횟수를 측정하기
- 보호자 인터뷰를 통해 "돈을 낼 이유"가 있는 문제인지 검증하기
- 첫 타깃을 보호자 가족형 서비스로 갈지, 지자체/기관형 서비스로 갈지 결정하기
- 실제 사용 전후 화면을 비교하는 짧은 시연 영상 만들기
- "디지털 교육보다 빠르고, 원격 조작보다 안전하다"는 메시지로 포지셔닝 강화하기
- 위험 행동을 막는 정책을 서비스 신뢰의 핵심 가치로 계속 가져가기

## 결론

큐는 고령층의 스마트폰 사용 문제를 매우 구체적인 순간에서 포착한 서비스입니다. 기술을 앞세우기보다 사용자가 직접 해냈다는 경험을 만드는 점이 좋고, 보호자와 기관까지 확장할 수 있는 사업적 여지도 있습니다.

아이디어톤 심사위원 관점에서 가장 중요한 보완점은 실제 사용자 검증과 첫 고객 정의입니다. 이 두 가지가 보강되면 큐는 단순한 접근성 앱을 넘어 고령층 디지털 자립을 돕는 실질적인 서비스로 성장할 가능성이 있습니다.
