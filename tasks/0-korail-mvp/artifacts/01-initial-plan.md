# Initial Plan: korail-mvp

## 요구사항 (무엇을 만들 것인가)

- 코레일톡 Android 앱 위에서만 동작하는 cuee MVP를 만든다.
- MVP는 사용자가 "예매한 표 보여줘" 또는 "승차권 예매 찾기"라고 말했을 때 다음에 눌러야 할 영역만 남기고 나머지를 흰색으로 가린다.
- 제품 포지셔닝은 "노인용 앱"이 아니라 모바일 거래 실패율이 높은 사용자에게 다음 행동을 보여주는 AI 접근성 인프라의 첫 wedge로 잡는다.
- 직접 사용자는 코레일톡 이용에 실패하는 고령자, 인지 부담이 큰 사용자, 방한 외국인으로 잡고, 초기 결제자는 보호자 가족과 교통/관광 사업자까지 확장 가능하게 설계한다.
- 첫 구현은 한국어 코레일톡 명령에 집중하고, 외국인은 발표 스토리와 UT 타깃에 포함해 언어 장벽 확장성을 검증한다.
- 아이디어톤 발표 문서는 모두가 같은 장면을 떠올리도록 코레일톡 예매 실패 장면, 하얀 마스킹, 남겨진 버튼, 사용자의 직접 터치를 중심 이미지로 통일한다.
- 사업 논리는 "출시하자마자 살 고객이 있다"를 증명하는 방향으로 보호자 B2C와 코레일/관광/교통 B2B를 모두 검증 가능하게 만든다.

## 구현 디테일 (어떻게 만들 것인가)

- Android Native Kotlin으로 구현하고 `AccessibilityService`, `AccessibilityNodeInfo`, `WindowManager.TYPE_ACCESSIBILITY_OVERLAY`, `SpeechRecognizer`, `TextToSpeech`를 사용한다.
- 코레일톡 package만 지원 대상으로 두고, 다른 앱은 MVP 범위에서 제외한다.
- 자동 클릭은 하지 않고, 사용자가 직접 누를 수 있도록 후보 영역 주변에만 overlay mask를 배치한다.
- 결제, 로그인, 인증번호, 개인정보, 예매 확정, 구매 확정 화면은 민감 화면으로 판단해 안내를 중단한다.
- 발표 안정성을 위해 실제 코레일톡 위 동작을 1순위로 구현하되, 실패 시 사용할 수 있는 최소 수동 검증 절차를 문서화한다.
- UT 설계를 포함해 예매 시작/표 확인 task에서 cuee 사용 전후 완료 시간, 실패율, 도움 요청 횟수를 비교할 수 있게 한다.
- B2C 가격 가설은 보호자 가족 기준 월 7,900원으로 둔다. 월 4,900원은 문제 강도 대비 약하고, 월 9,900원 이상은 첫 신뢰 형성 전 구매 저항이 커질 수 있으므로 초기 검증용 기준가는 7,900원이 적절하다.

## 제약 조건 (무엇을 안 할 것인가)

- MVP에서는 쿠팡, 카카오톡, 금융, 병원, 배달 앱을 지원하지 않는다.
- MVP에서는 코레일톡 내부 결제 완료, 자동 예매, 자동 로그인, 자동 클릭을 구현하지 않는다.
- MVP에서는 서버, 로그인, 원격 보호자 조작, AI API 기반 범용 화면 이해를 도입하지 않는다.
- 화면 텍스트 원문, 음성 원문, 승차권 정보, 개인정보, 검색어를 영구 저장하지 않는다.
- 외국인을 타깃에 포함하되, 첫 구현은 코레일톡 한국어 화면 위에서 다음 영역을 찾는 것으로 제한한다.
- 외국어 음성 명령 인식은 MVP 이후 확장으로 둔다. Android `SpeechRecognizer` locale 전환과 영어/일본어/중국어 command parser로 구현 가능하지만, 첫 MVP의 정확성과 일정에는 한국어 명령 2개가 유리하다.

## 완료 기준 (이번 라운드의 끝)

- `./gradlew :app:assembleDebug`가 통과한다.
- 코레일톡 위에서 cue bubble을 띄우고, bubble 탭 후 음성 요청을 받을 수 있다.
- "예매한 표 보여줘"와 "승차권 예매 찾기" 요청을 구분하고 코레일톡 현재 화면에서 후보 영역을 찾는다.
- 후보가 명확하면 후보 영역만 노출하는 흰색 마스킹 overlay를 표시한다.
- 결제, 인증, 로그인, 개인정보, 예매 확정 화면에서는 안내하지 않고 "직접 확인해 주세요" 상태로 멈춘다.
- parser, safety policy, 코레일톡 target matching 로직은 unit test로 검증한다.
- 발표/사업 문서에는 한문장 소개, 첫 고객, 구매 이유, 데미지, 베네핏, 때려잡을 대상, 올해가 적기인 이유, UT 측정 계획이 포함된다.
- UT 목표 수치는 코레일톡 표 확인/승차권 예매 시작 task에서 완료시간 50% 감소, 도움 요청 70% 감소, 실패율 30%p 감소로 둔다.
- B2B 확장 가설은 코레일 기준 디지털 실패로 인한 창구/콜센터/민원 전환을 줄이고, 교통약자·외국인 접근성 개선 성과를 수치화하는 솔루션으로 둔다.
